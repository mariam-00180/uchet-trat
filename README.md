# Учёт личных трат

## Описание проекта

Веб-приложение для учёта личных расходов, разработанное на языке Go с использованием SQLite.

Приложение позволяет управлять личными расходами через веб-интерфейс, регистрировать пользователей, просматривать статистику и экспортировать данные в CSV.

## Технологии

- Go
- net/http
- HTML и CSS
- html/template
- SQLite
- database/sql
- Переменные окружения для конфигурации

## Возможности

- Регистрация и вход пользователей.
- Добавление новых расходов.
- Просмотр списка расходов.
- Редактирование и удаление расходов.
- Сохранение данных в базе SQLite.
- Фильтрация расходов по категории и диапазону дат.
- Просмотр общей суммы и количества расходов.
- Просмотр статистики расходов.
- Экспорт расходов в CSV.
- Настройка параметров приложения через переменные окружения.
- Адаптивное оформление веб-интерфейса.

## Запуск проекта

1. Установите Go.
2. Скачайте или клонируйте репозиторий.
3. Откройте папку проекта в терминале.
4. При необходимости настройте переменные окружения, используя `.env.example` как образец.
5. Выполните команду:

```bash
go run .
```

6. Откройте браузер и перейдите по адресу:

http://localhost:8080

## Структура проекта

- `main.go` — запуск приложения.
- `db.go` — работа с базой данных.
- `web.go` — веб-сервер и обработчики запросов.
- `env.go` — настройки приложения.
- `static/style.css` — стили веб-интерфейса.
- `.env.example` — пример конфигурации.
- `go.mod` и `go.sum` — информация о модуле и зависимостях Go.
