# Учёт личных трат

Учебное веб-приложение для учёта личных расходов, разработанное на Go с использованием SQLite.

## Возможности

- Регистрация пользователей, вход и выход из аккаунта.
- Раздельное хранение расходов разных пользователей.
- Добавление, просмотр, редактирование и удаление расходов.
- Фильтрация расходов по категории и диапазону дат.
- Подсчёт общей суммы и количества расходов с учётом выбранных фильтров.
- Статистика расходов по категориям и месяцам.
- JSON API для получения статистики по категориям и месяцам.
- Отображение графиков с использованием Chart.js и Fetch API.
- Экспорт расходов текущего пользователя в CSV.
- Серверная проверка введённых данных.
- CSRF-защита POST-форм.
- Журналирование HTTP-запросов.
- Настройка параметров приложения через файл `.env`.
- Отдельный CSS-файл для оформления интерфейса.

## Используемые технологии

- **Go** — серверная логика, `net/http`, `html/template`.
- **SQLite** — хранение пользователей, сессий и расходов.
- **HTML и CSS** — структура и оформление страниц.
- **JavaScript** — взаимодействие с API.
- **Fetch API** — получение статистики.
- **Chart.js** — визуализация статистических данных.

## Требования

Для запуска необходимы:

- Go версии, совместимой с `go.mod`.
- Доступ к зависимостям Go при первой сборке.
- Браузер с поддержкой современного JavaScript.

## Установка и запуск

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/mariam-00180/uchet-trat.git
   ```

2. Перейдите в каталог проекта:

   ```bash
   cd uchet-trat
   ```

3. При необходимости создайте файл `.env` на основе `.env.example` и настройте параметры:

   ```env
   PORT=8080
   DB_PATH=expenses.db
   SESSION_SECRET=replace-with-a-long-random-secret
   ```

   Используйте собственное длинное случайное значение `SESSION_SECRET`. Не публикуйте файл `.env` и реальные секреты в репозитории.

4. Запустите приложение:

   ```bash
   go run .
   ```

5. Откройте приложение в браузере:

   `http://localhost:8080`

6. Создайте аккаунт и войдите в систему.

## Конфигурация

| Переменная | Назначение | Значение по умолчанию |
|---|---|---|
| `PORT` | Порт HTTP-сервера | `8080` |
| `DB_PATH` | Путь к файлу SQLite | `expenses.db` |
| `SESSION_SECRET` | Секрет для механизмов сессии, если используется реализацией приложения | Зависит от конфигурации |

Перед запуском проверьте `.env.example` и код приложения: фактическое использование каждой переменной должно соответствовать реализации.

## Проверка проекта

Для проверки компиляции и статического анализа выполните:

```bash
go test ./...
go vet ./...
```

Команда `go test ./...` запускает имеющиеся тесты. Если вывод содержит `no test files`, это означает, что пакеты не содержат тестовых файлов.

## База данных и миграция

Приложение использует SQLite. Файл базы данных по умолчанию называется `expenses.db`.

Перед запуском новой версии на существующей базе рекомендуется создать резервную копию. Поведение миграции зависит от реализации в `db.go`; проверьте изменения структуры таблиц и распределение старых записей перед использованием существующих данных.

Не загружайте базу данных с реальными пользовательскими данными в публичный репозиторий.

## Безопасность

- Используйте отдельные учётные записи для разных пользователей.
- Не публикуйте `.env`, секреты сессий и пользовательские данные.
- Храните локальные файлы базы данных вне публичных коммитов.
- Проверяйте серверную валидацию данных, права доступа и обработку ошибок перед развёртыванием приложения.

## Структура проекта

Основные файлы и каталоги:

- `main.go` — запуск приложения.
- `web.go` — HTTP-обработчики и логика веб-интерфейса.
- `db.go` — работа с базой данных и миграции.
- `env.go` — загрузка конфигурации окружения, если используется.
- `static/` — статические файлы, включая CSS.
- `templates/` — HTML-шаблоны страниц ошибок и другие шаблоны, если они используются.
- `.env.example` — пример конфигурации.
- `.gitignore` — файлы, исключённые из Git.
