# Учёт личных трат

Учебное веб-приложение для учёта личных расходов на Go и SQLite.

## Возможности

- Регистрация, вход и выход из аккаунта.
- Отдельные расходы для каждого пользователя.
- Добавление, просмотр, редактирование и удаление расходов.
- Фильтрация по категории и диапазону дат.
- Сумма и количество расходов по текущему фильтру.
- Статистика по категориям и месяцам.
- JSON API статистики и графики Chart.js через fetch.
- Экспорт расходов текущего пользователя в CSV.
- Проверка введённых данных, CSRF-токен для POST-форм и журнал запросов.
- Настройки из `.env` и отдельный CSS-файл.

## Технологии

- Go (`net/http`, `html/template`)
- SQLite (`modernc.org/sqlite`)
- HTML/CSS

## Запуск

1. Установите версию Go, совместимую с `go.mod`.
2. Скачайте репозиторий и откройте его папку в терминале.
3. При необходимости скопируйте `.env.example` в `.env` и настройте `PORT` или `DB_PATH`.
4. Скопируйте `.env.example` в `.env` и обязательно задайте собственное длинное случайное значение `SESSION_SECRET`. Если меняете секрет после запуска, пользователям может потребоваться войти снова.
5. Запустите приложение:

   ```bash
   go run .
   ```

6. Откройте `http://localhost:8080` (или порт из `PORT`).
7. Создайте аккаунт на странице регистрации.

## Данные и миграция

Приложение использует локальный файл `expenses.db`. Существующие таблица `expenses` и строки сохраняются; при старте добавляются недостающие столбцы `expense_date` и `user_id`. Старые записи с `user_id = 1` будут доступны первому аккаунту с ID 1. Сделайте резервную копию `expenses.db` перед запуском новой версии.

База данных и `.env` исключены из Git через `.gitignore`; не загружайте в публичный репозиторий реальные пользовательские данные.
