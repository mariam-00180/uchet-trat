# Учёт личных трат

Учебное веб-приложение для учёта личных расходов на Go и SQLite.

## Возможности

- Регистрация, вход и выход из аккаунта.
- Отдельные расходы для каждого пользователя.
- Отдельный слой доступа к данным `ExpenseRepository` в `repository.go`; HTTP-обработчики не выполняют SQL напрямую.
- Добавление, просмотр, редактирование и удаление расходов.
- Фильтрация по категории и диапазону дат.
- Сумма и количество расходов по текущему фильтру.
- Статистика по категориям и месяцам.
- JSON API статистики и графики Chart.js через fetch.
- Экспорт расходов текущего пользователя в CSV.
- Проверка введённых данных, CSRF-токен для POST-форм и журнал запросов.
- Настройки из `.env` и отдельный CSS-файл.

## Технологии

- Go (`net/http`, `html/template`)
- SQLite (`modernc.org/sqlite`)
- HTML/CSS, Chart.js
- bcrypt for password hashing

## Запуск

1. Установите Go 1.27.2 или совместимую более новую версию. При первом запуске Go может скачать зависимость `golang.org/x/crypto` (для bcrypt); для этого требуется доступ к Go module proxy.
2. Скачайте репозиторий и откройте его папку в терминале.
3. При необходимости скопируйте `.env.example` в `.env` и настройте `PORT` или `DB_PATH`.
4. Скопируйте `.env.example` в `.env`. `SESSION_SECRET` пока не используется текущей реализацией; не полагайтесь на него как на активную настройку безопасности.
5. Запустите приложение:

   ```bash
   go run .
   ```

6. Откройте `http://localhost:8080` (или порт из `PORT`).
7. Создайте аккаунт на странице регистрации.

## Данные и миграция

Приложение использует локальный файл `expenses.db`. Существующие таблица `expenses` и строки сохраняются; при старте добавляются недостающие столбцы `expense_date`, `user_id` и `category_id`; таблица `categories` заполняется базовыми категориями и категориями из старых записей. Пароли новых аккаунтов хранятся в формате bcrypt; старые PBKDF2-хэши остаются совместимыми и автоматически обновляются после успешного входа. Старые записи с `user_id = 1` будут доступны первому аккаунту с ID 1. Сделайте резервную копию `expenses.db` перед запуском новой версии.

База данных и `.env` исключены из Git через `.gitignore`; не загружайте в публичный репозиторий реальные пользовательские данные.
